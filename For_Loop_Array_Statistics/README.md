# For Loop Array Statistics

A beginner-friendly LabVIEW project that uses a **For Loop** and **shift registers** to process a numeric array and calculate basic statistical values.

## Features

The VI accepts a user-defined numeric array and calculates:

- **Sum** – Total of all array elements
- **Maximum** – Highest value in the array
- **Minimum** – Lowest value in the array
- **Average** – Arithmetic mean of the array

## Example

**Input Array:** `6, 4, 4, 2`

**Output:**
- Sum = `16`
- Maximum = `6`
- Minimum = `2`
- Average = `4`

## LabVIEW Concepts Demonstrated

- Numeric arrays
- For Loop
- Auto-indexing
- Shift registers
- Numeric data types
- Arithmetic operations
- Array size/count
- Front Panel controls and indicators

## How to Run

1. Open `For_Loop_Array_Statistics.lvproj` in LabVIEW.
2. Open `For_Loop_Array_Statistics.vi`.
3. Enter the required numbers in the **Input Numeric Array**.
4. Run the VI.
5. The **Sum, Maximum, Minimum, and Average** values are displayed in the Results section.

## Purpose

This project demonstrates practical use of a **For Loop for array processing** in LabVIEW and provides a foundation for developing more advanced test and automation applications.
